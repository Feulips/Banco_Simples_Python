# 🏦 Sistema Bancário em Python

Aplicação bancária desktop desenvolvida em Python com **CustomTkinter**, contendo dashboard, depósitos, saques e extrato.

## Funcionalidades

- 💰 Depósito
- 💸 Saque
- 📄 Extrato
- 💳 Saldo disponível
- 🔒 Limite de R$ 300,00 por saque
- 📊 Limite de 3 saques
- 🖥️ Interface gráfica desktop
- 🧩 Código separado entre lógica e interface

## Estrutura

```text
sistema-bancario/
├── main.py
├── banco.py
├── interface.py
├── requirements.txt
└── README.md
```

## Instalação

```bash
pip install -r requirements.txt
```

## Execução

```bash
python main.py
```

## Tecnologias

- Python
- CustomTkinter
- Tkinter/messagebox

## Objetivo

Projeto educacional para praticar Python, funções, classes, validação de dados, interface gráfica e organização de código.

> Projeto de estudo. Não deve ser utilizado para operações financeiras reais.
